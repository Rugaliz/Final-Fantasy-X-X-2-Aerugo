# Roadmap

Each milestone ends with something that runs.

| Milestone | Content | You can run |
|---|---|---|
| **M0 Foundations** | Workspace, CI, window, Vulkan bootstrap, game detection, archive reader, launcher, fixed tick with interpolation | The launcher, listing the installed games; a test scene that shows 30 Hz motion smoothly at any display rate |
| M1 Viewer | Readers for textures, models, skeletons, motions, maps, sounds, music, voices, videos, scripts and data tables; asset browser | Browse and view any asset of both games |
| M2 Runtime slice | Script runtime, map loading, characters, camera, message windows, player control, saves | Walk and talk in one area of FINAL FANTASY X |
| M3 FFX field | All field features, menus used in the field, cutscenes | A chapter of FINAL FANTASY X outside battles |
| M4 FFX battle | Battle system, commands, formulas, enemy behaviour, battle camera | Battles |
| M5 Effects | Spell and particle effects | Battles with all effects |
| M6 FFX complete | Remaining menus, sphere grid, minigames, ending | A full playthrough |
| M7 FINAL FANTASY X-2 | Shared runtime plus X-2 systems | A full playthrough |
| M8 Extras | Last Mission, Eternal Calm, credits and bonus audio | Every launcher entry |
| M9 1.0 | Polish, rebinding, performance at 8K / 240 Hz, packaging | A release |

Resolution, aspect ratio and frame-rate independence are part of the design from M0, not added at the end.
Modern rendering options, audio enhancements and mod support come after 1.0.
